# 神雕侠侣端游复原 · 阶段成果归档

本仓库保存截至 2026-10-24 的复原源码、结构化客户端资料、设计决策、研究报告与验证脚本。项目现阶段停止主动推进，保留成果供查阅和后续接手。

**这是开发中的研究快照，完整游戏尚未复原。** 源码、历史部署和真客户端验收是不同层次；历史报告通过不表示当前快照已整体通过，也不表示全部玩法可用。

## 已保存的成果

- 原客户端 PFS / 二进制 XML 读取、配置及地图资料恢复工具，结构化配置与界面描述。
- 本地认证、角色创建与持久化、加密连接及分区运行时；地图、NPC、碰撞、寻路、传送与恢复相关模块。
- 人物成长、资源与货币、背包装备、宠物、任务、新手流程、战斗、社交及家族帮派等模块的阶段实现。
- 规则来源与设计取舍、原生协议研究、离线验证和集成交接资料。模块存在不代表整套系统已可玩。

## 使用条件

基础服务代码使用 Python 3.12+；多数领域脚本仅依赖标准库。原生 x86 对照验证另需 Unicorn、对应原客户端映像及本地测试输入，部分工具包含历史机器路径，尚未全部迁移为可移植工具。

仓库不包含原客户端安装包、可执行程序、美术原包、内存映像、账号数据库、认证抓包或运行日志。启动真客户端需要自行准备相符版本的合法客户端文件。详见 [HANDOFF.md](HANDOFF.md)。

本次只做归档，不启动或重启现有服务，不操作玩家存档，也不新增玩法。完整实机验收、跨系统回归、多人压力和商用部署均未由本批验证。
