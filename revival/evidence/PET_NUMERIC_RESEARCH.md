# 宠物经验、成长与资质数值核验

日期：2026-10-23（Asia/Shanghai）。适用目标：本地端游 1.6.1 / 网络 601（项目既定范围）。本轮只读原包、离线映像及现有工具，再查端游公开资料；未启动游戏或改动生产代码、配置。

## 结论与来源等级

- `client_verified`：经验表存在两段键 `0–150`、`1001–1150`，共 301 行。原表提供数值，尚未证明两个区段各代表哪种成长状态、角色等级映射或经验扣除语义。不得将 ID 1001 当作宠物等级 1001。
- `client_verified`：500001 宠物的 `growrate` 是五个原整数 986、996、1006、1016、1026；五项资质上下限也在原表。尚无本轮原生调用证据证明原整数应除 1000 作为最终属性倍率。
- `guide_supported`：2013 年官方端游攻略把成长值 1256 解释为每级增加 12.56 点属性，含自由分配 5 点、系统分配 7.56 点。这支持“成长原值 / 100 → 每级总属性点”的历史规则候选；不是目标客户端完整公式的验证。
- `inferred`：`cpetproportion` 更符合体型随等级变化的比例表，不能接入战斗属性成长公式。其业务调用尚未定位，推断与实证分开。
- 精确缺口：经验索引选择及越界策略、成长点余数与系统分配、资质到派生属性的系数和运算顺序、初始属性与随机分布，均须后续客户端调用核验；仍无证据时由主策划登记 `designed`。

检索顺序为原包/离线映像在先、外部资料在后。排除 `sdxlsy.games.wanmei.com`、手游频道及《神雕侠侣2》。历史文章未明确绑定 1.6.1 / 601。

1. [官方端游《八技能宝宝打造攻略》，2013-10-23](https://sdxl.wanmei.com/news/gamenews/20131023/151950.shtml)：已打开正文。解释成长 1256 对应每级 12.56 属性点、5 点自由分配、剩下系统分配；用“一点力量增加 1.4 外伤”作说明，但未提供此例的资质，不能当作所有宠物通用系数。此文自称“大致可以理解”，故为 `guide_supported`，不能替代精确调用。
2. [官方端游《宠物资质》，2012-07-29](https://sdxl.wanmei.com/info/qita/pet/20120729/133549.shtml)：确认外功/防御/体力/内功/速度资质影响方向，没有从资质整数到属性的计算式。

4. [官方端游《宠物卡牌发布》，2012-07-02](https://sdxl.wanmei.com/news/gamenews/20120702/132143.shtml)：品质关联成长资质、升级增长；未公布档位抽样概率。

## 可供主策划设计的精确缺口

| 缺口 | 已知约束 | 需要裁定或继续核验的字段 |
| --- | --- | --- |
| 宠物经验 | 原表值与分组均保留 | `ordinary_id(level)`、1000 段适用状态、从 0/1 起算、当前级/下一级、消费还是累计、最高级与溢出经验处理 |
| 成长率单位 | 官方历史攻略支持每级总点约为 growrate/100 | 是否适用于此客户端、单位、每级自由点、初始等级累计、系统五维分配、余数保留与取整时机；禁止默认 /1000 乘最终属性 |
| 初始生成 | 原资质上下限和五档成长可取 | 品质到档位映射、取样概率、边界包含、初始等级与五维点数、是否回溯成长 |
| 五维→派生属性 | 官方只给资质影响方向 | HP/MP/外伤/外防/内伤/内防/速度的基值与交叉项、资质归一化、成长参与位置、技能/血脉/进化加成顺序、取整和上限 |
| 体型与进化 | proportion 与 evolution 是独立表 | 先按外观候选隔离；进化增加成长的具体量、重算还是仅后续升级另查 |

可采用历史攻略支持的成长方向帮助设计，但采用的除数、余数/分配规则及派生属性公式必须逐项标 `guide_supported`、`inferred` 或 `designed`，不能把整套标为 `client_verified`。本研究不新增设计值，不改写共用裁定。
